Salvar entre aparelhos

Seu progresso sempre fica salvo neste navegador. Para ter o mesmo progresso no celular e no computador, conecte um token do GitHub: o site guarda tudo num gist secreto da sua conta, sem banco de dados.

Conectado ao GitHub

No GitHub: Settings › Developer settings › Personal access tokens › Fine-grained tokens. Em “Account permissions”, dê a permissão Gists: Read and write. O token fica só neste aparelho.

Como funciona o XP

Aulas

  • Aula da grade principal +10 XP
  • Aula complementar +15 XP
  • Missão de prática (passos 10 e 12) +20 XP
  • Unidade inteira concluída +25 XP

Estações concluídas

  • Essencial +300 XP
  • Muito importante +200 XP
  • Importante +120 XP
  • Opcional +80 XP
  • Missão extra +100 XP

Hábitos

  • Conversação em grupo +30 XP
  • MemHack no dia +5 XP
  • Meta da semana cumprida +100 XP
  • A meta da semana também dá 1 escudo. Ele salva sua sequência se você perder um dia. Você guarda até 2.
